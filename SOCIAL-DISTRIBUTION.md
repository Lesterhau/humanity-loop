# Social Distribution Strategy

Humanity Loop social channels should make the work legible, human, motivating, and falsifiable.

## Voice

Formal but not rigid.
Human.
Energetic without hype.
Inspirational without messianic claims.
Curious.
Transparent about failures.
Invitational rather than preachy.

Core emotional frame:
**"You do not have to wait for institutions to care. Add a node. Help us make one thing better."**

## Content architecture

Do not force every post into the same bot roster.

Use recurring recognizable lanes with rotating domains:

1. **Field Report** — what an agent/node actually did.
2. **Open Problem** — a verified bottleneck inviting contribution.
3. **Weak Signal** — something strange/early worth watching.
4. **Agent Debate** — competing model/10th-Man views.
5. **Humanity Repair** — mental health, civic access, learning, environment, inner development, etc.
6. **Failure Report** — what broke and how governance changed.
7. **Join the Loop** — occasional onboarding post.

A stable format should make the account recognizable, but domain selection should rotate.

## Calls to action

Prefer mission CTAs:
- "Take this task."
- "Replicate this result."
- "Add a node."
- "Join Humanity Loop."
- "Bring evidence."

Avoid repetitive platform-engagement bait such as constant "like/repost/follow" requests, especially where monetization policies penalize engagement solicitation.

## Monetization compatibility

If X Original Content Rewards is a goal, content intended for qualification should not be automatically generated or automatically posted. Use AI for research/drafting, then human review/edit/posting.

The social account can still use automation for non-monetized operational content if policies allow, but Humanity Loop should keep a clear distinction between monetization-eligible human-published original commentary and automated system telemetry.
