## Finding

Humanity Loop should not assume it must independently build or recruit an entire public-good agent ecosystem before exploring compatible, already visible communities. Two distinct efforts provide a bounded comparison:

1. **Agentic Commons** — https://agentic-commons.org/ . The public site describes a public-good agent-contribution network, upstream-native submissions and machine-readable project/contribution identifiers. Its **read-only** API at https://agentic-commons.org/api/v1/projects lists public-good projects and self-reported task/contributor counts, including MusicBrainz, OpenLibrary, Open Food Facts and Wikidata work. These counts are **platform records, not independently verified upstream acceptance or beneficiary impact**. Its public OpenAPI document at https://agentic-commons.org/openapi.json describes GET endpoints only; project opt-in/out contact channels are described as forthcoming, and the organization says it is still in formation. A partnership, enrollment route or live reciprocal bridge is **not established**. This is the stronger *future federation/discovery* lead, but **not** a presently verified path for an independent operator to complete Humanity Loop's issue #29.
2. **AI Commons** — https://github.com/tartalonllc/ai-commons . Its source README (independently read from GitHub on 2026-10-28) describes local volunteer inference with worker-controlled API spending caps and project/task validation. It explicitly says **there is no public coordinator**, its Windows installer is unsigned and its multi-machine acceptance remains incomplete. This is an architecture and potential future collaboration lead, **not** an immediately usable public Humanity Loop node-acquisition channel. Do not ask its maintainer to connect an unready public coordinator or imply cross-platform compatibility.

## Decision and next bounded action

**No external contact now.** There is no verified invitation or project-onboarding channel from Agentic Commons, and AI Commons lacks a public coordinator. Do not register a synthetic agent, submit a project via undocumented endpoints, auto-reply to social posts, scrape private operator identities, or claim these platforms are affiliated with Humanity Loop.

**Next owner action (2026-10-30 or upon a real published opt-in route):** Recheck Agentic Commons' official project opt-in/contact documentation and whether a human-operated independent browser reviewer can voluntarily discover and complete Humanity Loop's existing [Tier-0 issue #29](https://github.com/Lesterhau/humanity-loop/issues/29) through an explicitly permitted channel. If a legitimate contact route appears, prepare **one** human-reviewed, specific invitation explaining the bounded read-only task; send only if permitted and nonduplicative. Independently measure a real reply/submission, not impressions, listings or platform task counts.
