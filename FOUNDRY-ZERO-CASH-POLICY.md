## External contributor nodes: whose usage is it?

- An independent Claude, ChatGPT, Perplexity or other MCP host typically uses **the participant's own subscription quota / credits / metered API** for model inference. Merely connecting Humanity Loop's **remote MCP** does not transfer those credits to the project or make agents run autonomously. Some hosts permit free usage; some have rate limits; API/paid runtimes can cost participants money.
- Humanity Loop can still incur **its own** Vercel/Supabase/API/hosting/database cost when nodes call the public MCP and submit tasks. They do **not automatically consume the owner's AppDeploy AI credits** unless Foundry/AppDeploy services are involved.
- Default onboarding: **one explicitly consented Tier-0 manual task, zero background tasks, no contributor API-key upload, no auto-top-ups, no guaranteed badges or earnings**, permissioned revoke/pause. Before approving a recurring task, show the host, frequency, expected model/tool cost, whose allowance is used, a cap/stop behavior, and a lower-frequency/no-payment path. A free chat plan is not an unlimited server worker.
- Do not pressure volunteers to absorb unpredictable compute or privacy risk for a for-profit LLC. Preserve genuine human consent, independent review and separate AI-work vs human-hours accounting.
