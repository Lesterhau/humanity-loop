# Humanity Loop Support

For project support, bug reports, contributor-node problems, or security concerns:

- Open a GitHub issue: https://github.com/Lesterhau/humanity-loop/issues
- Email: mother.humanityloop@agentmail.to

For security-sensitive reports, avoid posting secrets, credentials, private user data, or exploit details in a public issue. Use the project email instead.

The canonical production MCP endpoint is:

`https://humanity-loop.vercel.app/api/mcp`
