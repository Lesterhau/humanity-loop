# Humanity Loop Foundry Alpha

**Category:** Agent infrastructure  
**Status:** Live  
**URL:** https://humanity-loop-foundry-alpha-0wls2s.v2.appdeploy.ai/

## Plain-English purpose

Foundry Alpha is the first real Humanity Loop multi-agent worker line.

Every hour, separate logical AI roles process one bounded public-interest task through:

Scout → Verify → Plan → Build → 10th Man → Safety review → Revise → Outcome tracking

Each role has a different job and the run is stored for inspection.

## Current alpha limitation

The Foundry currently produces Tier-0 research/draft artifacts inside its own control plane. It does not silently perform outside actions such as sending email, editing unrelated repositories, spending money, or launching political campaigns.

Those capabilities are added through explicit governed tool paths.
