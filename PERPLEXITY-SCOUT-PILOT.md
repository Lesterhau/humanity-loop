# Perplexity Computer — Humanity Loop source-first Scout pilot

**Status: ready for owner-controlled setup, not scheduled/connected/verified.** Owner has an existing paid Perplexity subscription. Do not assume ChatGPT can remotely change the Perplexity account or create a job from this repository. No API purchase, external credential, quota top-up or new Humanity Loop GitHub Actions schedule required.

## Why Perplexity, and why only one pilot?

The main ChatGPT hourly worker already operates Humanity Loop, and Claude's owner-configured four-hour cloud task covers due case reviews. **Perplexity should do new external-source discovery**, not duplicate VA/WIC/SSA follow-ups, AppDeploy maintenance, branch reviews or MOTHER posts. Gemini on the owner's educational account can independently test a small subset of Scout claims **after** the Perplexity source quality and handoff have been measured.

Perplexity Computer Automations (as publicly documented October 2026) can run on schedule, remember previous runs and use web research; runs spend account usage credits. Begin with **one daily, limited-scope read-only automation for seven days**, not hourly or multiple autonomous bots. Stop if repeated sourcing errors, high usage, duplicate findings, spam requests or unexpected account access occur.

## Fixed first-week scope

**Global public-interest Scout with alternating daily lenses**, weighted toward:
- Defensive resilience against AI-swarm-enabled security threats to critical infrastructure, electric/water systems, banks/payments, hospitals, telecommunications and interconnected supply chains (research only; no live probing).
- Validated public-information correction opportunities and service accessibility.
- Credible, promising open-source scientific/public-good projects seeking contributors rather than generic news headlines.
- Global educational access, climate adaptation and neglected infrastructure vulnerabilities.

Each run selects **one concrete, independently source-checkable potential action**, then evaluates it against existing solutions and whether a legitimate actor could realistically use our help. Empty/no-signal output is acceptable. Do not promise anyone a service or invent beneficiaries.

## Paste-ready setup request for Perplexity Computer

> Create **one daily recurring Computer Automation** titled **Humanity Loop — Global Opportunity Scout (pilot)**. For the first seven runs, limit work to approximately one focused public-source research investigation per day. Do not spawn subagents that contact anyone, spend additional money, use account/private connectors, create more schedules, publish, modify GitHub or run live penetration tests.
>
> At the beginning of every run read the latest public Humanity Loop `PERPLEXITY-SCOUT-PILOT.md`, `PROJECT-STATE.md`, `SCOUTING.md` and `SCOUT-MESH.md`. Select a genuinely fresh global problem/solution lead, alternating domains so daily work does not become another repetitive news brief. Favor defensible public-interest tasks, existing technical solutions needing legitimate partners or scrutiny, and defensive AI-swarm resilience where appropriate.
>
> Verify the original source, its date and claims. Seek an independent second source. Assess: affected population; problem and timely evidence; existing solutions and duplication; falsifiable uncertainty; practical low-risk next action; likely legitimate partner; and the smallest useful deliverable. If no opportunity survives, record a transparent `no-signal`, not a manufactured proposal.
>
> **Output at most one candidate** per run in a structured compact block: `runAt`, `topic`, `sourceUrls`, `sourceDates`, `novelty`, `existingSolutions`, `whyNow`, `risks`, `proposedTier0Action`, `falsificationTest`, `handoffStatus`. For the initial pilot, `handoffStatus=not_connected` until Humanity Loop independently confirms a write/receipt in its own queue. No claim that a Perplexity result has reached ChatGPT from a Computer session alone.
>
> **No outside actions**: no emails, contacts, outreach, external account writes, deployment, code changes, unsafe threat instructions, social replies, or paid API calls. If a finding is too weak, discard it. Only notify the owner about an unavoidable decision or major externally meaningful evidence.
>
> Do not count completion of the scheduled Computer run as a Humanity Loop outcome. A genuine result must eventually enter an authorized, independently verified shared intake before any additional worker or public MOTHER content is triggered.

## First acceptance criteria

1. Owner sees a real Perplexity Automation schedule and the first run's history, with total account usage remaining reasonable.
2. At least one run produces original primary-source links and an independently checkable claim; or a credible no-signal finding.
3. The output honestly labels delivery `not_connected`; no false cross-model integration.
4. Existing ChatGPT worker can eventually read an authorized public-safe result without owner copy/paste. **This bridge has NOT been built; do not assert it exists.**
5. Only after an independent useful first-week pilot should workload/frequency expand. Any additional worker must have a bounded role and observable unique value.
