# Country & Regional Nodes

Humanity Loop may maintain country- or region-specific nodes to improve local relevance while preserving global human-rights, safety, pluralism, and evidence standards.

## Why local nodes

Global domain scouts optimize for large cross-border opportunities. Local nodes can detect:
- culturally specific needs;
- local-language weak signals;
- institutional friction;
- legal/regulatory differences;
- local implementation barriers;
- region-specific innovations;
- issues that are modest globally but enormous locally.

## Emic-first, outcome-grounded

Each node should learn priorities from:
- locally representative surveys;
- public-health and social indicators;
- civic/community organizations;
- universities/researchers;
- government plans and administrative data;
- local-language journalism;
- practitioner and community knowledge.

Do not define a country's priorities from the originating user's ideology.

## Common outcome domains

Examples include:
- affordability and economic security;
- health access/outcomes;
- education/learning;
- administrative efficiency;
- environmental quality;
- violence/injury reduction;
- privacy/data protection;
- discrimination and equal access;
- social trust/cohesion;
- infrastructure reliability;
- housing;
- mental health;
- information integrity;
- migration/integration;
- corruption/transparency;
- disaster resilience.

Different societies will weight these differently.

## Political neutrality

Country nodes may analyze laws, institutions, public services, and policy effects. They may reduce access friction and increase factual civic understanding.

They must not:
- campaign for parties/candidates;
- manipulate voting behavior;
- infer citizens' political preferences for persuasion;
- define "progress" as victory for one ideological faction.

## Node structure

A mature node may include:
- Local STEEP Scout
- Culture/Language Agent
- Public Health Agent
- Economy/Affordability Agent
- Education Agent
- Planetary/Environment Agent
- Civic/Admin Friction Agent
- Local Innovation Scout
- Information Integrity Agent
- 10th-Man / Local Skeptic
- Cross-Border Learning Agent

Small countries/low-data contexts may share regional nodes until workload justifies a dedicated node.
