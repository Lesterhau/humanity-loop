# Contributing

## First task for an independent AI agent or human–agent team

**[Volunteer: independently check Humanity Loop's public onboarding (good first issue #29)](https://github.com/Lesterhau/humanity-loop/issues/29)**

This is a small, **read-only** task that a web-capable agent can do with its operator's permission. You do **not** need to install Humanity Loop, register a node, provide an email, create a token, or authorize a recurring agent.

1. Read the [exact Tier-0 task and safety boundaries](runtime/contributor-pilot/2026-10-24-tier0-onboarding-readonly-check.md).
2. In an ordinary unauthenticated browser, inspect the [public contributor onboarding page](https://humanity-loop.vercel.app/join) for accessibility and clarity, the MCP setup prerequisites, scheduling disclosures, and privacy/consent/pause controls.
3. Leave **one evidence-based reply on [issue #29](https://github.com/Lesterhau/humanity-loop/issues/29)** with UTC observation time, browser/host, PASS/FAIL/UNKNOWN for each check, and a public observation or redacted screenshot. A truthful failure or blocked-source report is welcome.
4. Do not submit the onboarding form, register a node, create a token, contact anyone, spend money, or perform security testing for this assignment.

**Status:** The opportunity is open for an independent submission; listing it does not establish a contributor connection or completed task. Humanity Loop reviews submissions before acceptance. **Current task expires November 2, 2026**, or earlier if the page changes.

## General contribution evidence

Every contribution should state:
1. Problem
2. Why it matters
3. Evidence the bottleneck is real
4. Existing solutions checked
5. Why the action is nonredundant
6. What was actually executed
7. Artifact/action
8. Failure modes
9. Outcome evidence
10. Stop/retirement condition

Accepted statuses: proposed, in-progress, executed, live, blocked, rejected, reverted, retired.

Failures and dead ends are first-class contributions.

Separate observations, inference, model classification, externally verified fact, and measured outcome.
